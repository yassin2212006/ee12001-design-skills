# EE12001 Design Skills (Year 1)

Coursework portfolio from my first year of engineering at the University of Bath (2024-25). It shows the practical design, electronics and programming skills I built in the first year.

## What it covers

### Circuits and instrumentation
Op-amp interface circuit design, simulation and realisation, and testing of op-amp circuits on a breadboard.
- Files: `opamp_circuit_design_1.jpeg`, `opamp_circuit_design_2.jpeg`, `opamp_breadboard_test_1.jpeg`, `opamp_breadboard_test_2.jpeg`

### PCB design and manufacture
Design of a printed circuit board for a modular side-illuminated LED display built around an Arduino Nano ESP32 with RGBY LEDs and etched acrylic sheets (board size 41.91 x 60.96 mm, tolerance +/- 0.1 mm), including target specifications, a design and development matrix and a life cycle assessment.
- Files: `pcb_design_screenshot.png`, `report_modular_led_display.pdf`, `final_datasheet.pdf`, `technical_report_arduino.pdf`

### Programming and embedded systems
MATLAB fundamentals, embedded systems design, and programming with a hardware description language (waveform simulation), plus a data analysis task in project week 3.
- File: `code_project_week_3.pdf`

### Mechanical design and manufacture
CAD for 3D parts, assemblies and drawings, and additive manufacturing.
- Files: `cad_simple_part.png`, `assembly_drawing.pdf`

### Other skills evidenced
Data analysis and visualisation, sustainability and life cycle assessment, technical report writing, datasheet creation, project and time management, risk assessment, teamwork and research skills.
