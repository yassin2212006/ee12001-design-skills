# EE12001 Design Skills (Year 1)

Coursework portfolio from my first year of engineering at the University of Bath (2024-25). It shows the practical design, electronics and programming skills I built in the first year.

## What it covers

### Circuits and instrumentation
Op-amp interface circuit design, simulation and realisation, and testing of op-amp circuits on a breadboard.
- Files: `opamp_circuit_design_1.jpeg`, `opamp_circuit_design_2.jpeg`, `opamp_breadboard_test_1.jpeg`, `opamp_breadboard_test_2.jpeg`

### PCB design and manufacture
Design of a printed circuit board for a modular side-illuminated LED display built around an Arduino Nano ESP32 with RGBY LEDs and etched acrylic sheets (board size 41.91 x 60.96 mm, tolerance +/- 0.1 mm), including target specifications, a design and development matrix and a life cycle assessment. I also designed, laid out and had a small 555-timer LED flasher board made (USB-C powered), shown in a 3D view.
- Files: `pcb_design_screenshot.png`, `pcb_3d_view.png`, `report_modular_led_display.pdf`, `final_datasheet.pdf`, `technical_report_arduino.pdf`

### Programming and embedded systems
MATLAB fundamentals, embedded systems design, and programming with a hardware description language (HDL). The HDL waveform simulation checks a combinational circuit: output Z goes high when (A and B) is true or when C or D is high, which matched the defined logic. Also a data analysis task in project week 3.
- Files: `code_project_week_3.pdf`, `embedded_systems_design.pdf`, `hdl_questasim_waveform.png` and `hdl_questasim_compile.png` (QuestaSim simulation), `matlab_fundamentals_certificate.pdf` (MathWorks, Dec 2024)

### Mechanical design and manufacture
CAD for 3D parts, assemblies and drawings, and additive manufacturing.
- Files: `cad_simple_part.png`, `cad_assembly_exploded_view.png`, `cad_assembly_front_view.png`, `assembly_drawing.pdf`, `3d_print_prusaslicer_preview.png` (PrusaSlicer preview of the printed parts)

### Design process and project work
Design and development process, design matrix, verification of target specifications, a project timetable and the project week 3 teamwork report.
- Files: `dp_design_and_development_process.xlsx`, `dp_design_matrix.xlsx`, `dp_verifying_target_and_specification.xlsx`, `dp_project_week_3_timetable.pdf`, `dp_teamwork_project_week_3.docx`

### Other skills evidenced
Data analysis and visualisation, sustainability and life cycle assessment, technical report writing, datasheet creation, project and time management, risk assessment, teamwork and research skills.
